# Pixel Prix

A retro, NES-style pseudo-3D arcade racer in a single HTML file. Race through five stages against the clock, dodge traffic, and use nitro to beat the timer.

**Play:** https://erd-auto.github.io/pixel-prix/

## Controls

**Keyboard**
- Steer: Left/Right arrows or A/D
- Brake: Down arrow or S
- Nitro / start: Up arrow, W, Space or Enter
- Pause: P or Esc
- Mute: M

**Touch**
- ◀ / ▶ buttons: steer
- BRK: brake (hold)
- N2O: nitro boost
- Tap the screen to start or resume
